# CRO contract 05

This clean-room family covers independently specified implementations across
its active CRO units. A private-target analyst supplied a neutral behavioral
contract. A separate implementation agent, without access to the ROM, private
target objects, target disassembly, or the private report, authored the active
sources from that contract.

A provenance-quarantined unit formerly included in this family is not endorsed
by this contract and carries no active source or match credit.

`scripts/validate-cro-contract-05.mjs` retains the shared-family validation for
the remaining active sources. Authoritative objdiff comparison determines
their published match status. The family contract grants no whole-unit
completion claim.
